🛠️ NXTSTIM Automation Suite




Welcome to the Nxtstim end-to-end automation test framework. This project utilizes a hybrid BDD architecture combining Cucumber (Gherkin) for human-readable business logic criteria with Playwright (JavaScript) and Page Object Models (POM) for high-speed, reliable browser orchestration.



🚀 Pre-requisites \& Global Tools

Before setting up, make sure you have the following software installed on your machine:



Git: Download \& Install Git

Node.js: Download Node.js (LTS Version)

VS Code: Download Visual Studio Code

🔌 Required VS Code Extensions

Open VS Code, press Ctrl + Shift + X to open the Extensions marketplace, and install:



Cucumber (Gherkin) – by Cucumber

Playwright Test for VSCode – by Microsoft

Prettier - Code formatter – by Prettier

📦 Quick Start (After Cloning from GitHub)

If you are cloning this project from the repository, simply run these commands in your terminal:



\# 1. Clone the repository down to your machine

https://github.com/iqrafarooq-cloud/Nxtstim.git

\# 2. Navigate straight into the project root directory

cd "Nxtstim"



\# 3. Install all pre-configured dependencies instantly

npm install



\# 4. Run the Test Suite

npm run test
